## PREDICTIVE MAINTENANCE PROTOTYPE FOR MAIN ENGINES

This project is a predictive maintenance prototype deveoped with machine learning to support the monitoring and maintenance of main engines. 
It utilizes field data from Nigerian Navy Ships to assess and monitor engine conditions, predicting maintenance needs.
This is aimed at reducing downtime through breakown, improving enngine maintenance process and improving performance.

## Key Features
Marine engine conditions monitoring and prediction.
Data-driven maintenance decision support.
Interactive web interface using Streamlit.

## Methodology
Collected and used real operational engine data from Nigerian Navy ships.
Data cleaning and selection of relevant marine engine parameters for analysis and model development.
Machine learning model development and validation.
Deployed through Streamlit for real-time interaction.
